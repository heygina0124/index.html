# Explainer Studio

Figma · ElevenLabs · Remotion으로 SaaS 설명 영상(60초, 16:9 + 9:16)을 만드는 Claude Code 작업 폴더입니다.

## 구조
```
explainer-studio/
  .claude/skills/explainer/   ← /explainer 스킬 (SKILL.md, templates, reference, scripts)
  projects/                   ← 프로젝트별 작업 폴더 (/explainer가 생성)
  library/music/              ← 라이선스 음원 (예: upbeat-tech_118bpm.mp3)
```

## 사용
```
cd explainer-studio
claude
/explainer
```

처음 설치는 [`.claude/skills/explainer/SETUP.md`](.claude/skills/explainer/SETUP.md)를 따르세요.
